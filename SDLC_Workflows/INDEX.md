# SDLC Workflows Directory (Complete 18 Core Use Cases)

This directory contains the workflow models for all 18 core use cases of the Craft Atelier platform. We strategically split our modeling approach between **Activity Diagrams** (for complex operational control flows) and **Data Flow Diagrams (DFDs)** (for complex data, financial, and API interactions).

---

## 🔁 Complex Control Flows (Activity Diagrams)
1. **`UC-04_Interactive_Tutorial.md`**: Video navigation and looping.
2. **`UC-05_Panic_Button_SOS.md`**: Interrupt-driven WebRTC support escalation.
3. **`UC-06_Left_Handed_Mirror.md`**: UI state transformations for accessibility.
4. **`UC-07_Scan_BOM.md`**: Physical warehouse packing and scanning loops.
5. **`UC-08_Flag_Stock_Exception.md`**: Physical warehouse exception routing for damaged goods.
6. **`UC-09_Batch_Dispatch.md`**: Geolocation grouping and Boda Rider assignment.
7. **`UC-10_Input_Delivery_PIN.md`**: Multi-actor chronological chain-of-custody verification.
8. **`UC-17_Review_Support_Escalations.md`**: Customer support triage and branching logic.

---

## 💾 Complex Data Interactions (Data Flow Diagrams)
9. **`UC-01_Checkout_Pay.md`**: Standard M-Pesa STK push and order creation.
10. **`UC-02_Bulk_CSV_Upload.md`**: Corporate B2B data parsing and batch DB insertion.
11. **`UC-03_Modular_SKU.md`**: Aggregation of raw materials to construct dynamic kit catalogs.
12. **`UC-11_Update_Business_Settings.md`**: Admin config changes and cache invalidation.
13. **`UC-12_Manage_Global_Inventory.md`**: Warehouse count reconciliation and delta updates.
14. **`UC-13_View_Financial_Audit_Logs.md`**: Read-only financial lineage extraction.
15. **`UC-14_Generate_Tax_CSV.md`**: ETL pipelines for KRA e-TIMS compliance formatting.
16. **`UC-15_View_Royalty_Dashboard.md`**: RLS-secured dashboard rendering for creators.
17. **`UC-16_Disburse_Royalties.md`**: Mass M-Pesa B2C payouts via asynchronous ledgers.
18. **`UC-18_Process_Customer_Refund.md`**: Multi-ledger deduction (Company & Creator).
