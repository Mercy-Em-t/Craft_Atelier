# SDLC Navigation State-Machine Models

This directory contains the strict UI navigation state-machine models for the 3 highest-priority Use Cases in our system (The Top 3 'Must-Be' features from our Kano Analysis). 

Because a unified state machine of the entire enterprise software would be a massive, unreadable spiderweb, we have decomposed the architecture into an overarching routing diagram and 3 isolated sub-machines.
